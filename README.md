# R-UI-EDITOR

Editor visual de interfaces para **Roblox Studio** con lienzo libre, plantillas interactivas, biblioteca de iconos HD y exportación directa a Roblox.

Descarga la última versión en [**Releases**](https://github.com/Creampy-bit/roblox-ui-editor/releases/latest).

## Descarga e instalación

### Windows
- Descarga **`R-UI-EDITOR-Setup-<versión>.exe`**.
- Si Windows SmartScreen avisa que el editor es desconocido: **Más información → Ejecutar de todas formas**.
- Se actualiza automáticamente.

### macOS
- **Mac con Apple Silicon (M1 / M2 / M3 / M4):** descarga **`R-UI-EDITOR-<versión>-mac-arm64.dmg`**.
- **Mac con procesador Intel:** descarga **`R-UI-EDITOR-<versión>-mac-x64.dmg`**.
- Abre el `.dmg` y arrastra **R-UI-EDITOR** a **Aplicaciones**.
- La primera vez que lo abras (al no estar firmado con certificado de Apple Developer), haz **clic derecho → Abrir** o ejecuta en Terminal:
  ```bash
  xattr -cr /Applications/R-UI-EDITOR.app
  ```

### Linux
- **Universal (cualquier distro):** descarga **`R-UI-EDITOR-<versión>-linux-x64.AppImage`**, dale permisos de ejecución (`chmod +x R-UI-EDITOR-*.AppImage`) y ejecútalo. Incluye actualizaciones automáticas.
- **Ubuntu / Debian / Mint / Pop!_OS:** descarga **`R-UI-EDITOR-<versión>-linux-x64.deb`** e instálalo con:
  ```bash
  sudo apt install ./R-UI-EDITOR-*.deb
  ```
